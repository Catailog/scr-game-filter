# scr-game-filter

스타크래프트(리마스터) 방목록 검색을 편하게 만들어 주는 작은 프로그램입니다.

게임 안의 방 검색은 단어를 하나만 칠 수 있어서, 여러 조건을 보려면 하나씩 따로 검색해야 합니다. 이 프로그램을 켜 두면 방 검색창에서 이런 검색이 됩니다.

- `abc,def` : abc 또는 def가 들어간 방을 한 번에 보기
- `abc,-def` : abc가 들어간 방 중에서 def가 들어간 방은 숨기기
- 검색창에 아무것도 안 써도 항상 적용되는 "기본 필터" 설정하기

## 사용 방법

1. 이 저장소의 **Releases** 페이지에서 `scr-game-filter.exe`를 받습니다. 설치는 필요 없고, 관리자 권한도 필요 없습니다.
2. 원하는 폴더에 두고 실행합니다.
3. 창에 **프록시 동작 중...** 이라고 보이면 준비된 것입니다.
4. 스타크래프트를 켜고 방목록 화면의 검색창에 평소처럼 검색어를 입력합니다.

스타크래프트를 먼저 켜도, 이 프로그램을 먼저 켜도 상관없습니다. 단, 프로그램을 켠 뒤에 방목록 패널을 한 번 열어야 적용됩니다. 이미 열려 있었다면 닫았다가 다시 여세요.

사용이 끝나면 창을 닫으면 됩니다. 창을 닫으면 모든 것이 원래대로 돌아갑니다.

## 검색어 쓰는 법

| 입력 | 의미 |
|---|---|
| `abc` | abc가 들어간 방 |
| `abc,def` | abc 또는 def가 들어간 방 |
| `abc def` | "abc def"라는 문구가 그대로 들어간 방 (공백은 구분자가 아니라 글자입니다) |
| `-def` | def가 들어간 방을 숨김 |
| `abc,-def` | abc가 들어간 방 중에서 def가 들어간 방은 숨김 |
| `abc,,` | 쉼표를 연달아 쓰거나 맨 앞이나 맨 끝에 쓰면 전체 보기 |
| `\,` | 쉼표 글자 그대로 (예: `a\,b`는 "a,b"를 찾음) |
| `\-` | 하이픈 글자 그대로 (예: `\-def`는 "-def"를 찾음) |
| `\\` | 역슬래시 글자 그대로 |

- 여러 조건은 **쉼표로만** 구분합니다. 쉼표 앞뒤의 공백은 무시됩니다.
- 역슬래시(`\`)는 위 세 가지 이스케이프로만 쓸 수 있습니다. 그 외의 `\x`처럼 잘못된 조합은 역슬래시와 뒤의 한 글자까지 통째로 없는 것으로 취급하고, 맨 끝의 역슬래시도 무시합니다.
- 대소문자는 구분하지 않습니다.
- 숨기기(`-`)만 쓰면 나머지 방은 전부 보입니다. 예를 들어 `-def`는 def가 들어간 방만 빼고 다 보여 줍니다.
- `-`만 단독으로 쓰면 무시됩니다.
- 줄바꿈이라는 개념은 없습니다. 기본 필터 입력칸에서 Enter는 눌러도 입력되지 않고, 줄바꿈이 들어 있는 글을 붙여넣으면 줄바꿈만 지워집니다.

## 검색할 항목 고르기

창의 체크박스로 검색어를 어느 항목에서 찾을지 고릅니다. 처음에는 방 제목과 맵 이름만 켜져 있고, 게임 타입과 방장 이름은 꺼져 있습니다.

- 방 제목
- 게임 타입
- 맵 이름
- 방장 이름

숨기기(`-`)도 같은 항목에서 찾습니다. 예를 들어 방 제목만 체크해 두면 `-def`는 제목에 def가 들어간 방만 숨기고, 맵 이름이나 방장 이름에 def가 있는 방은 그대로 둡니다. 항목은 최소 한 개는 켜져 있어야 합니다.

## 기본 필터

창 가운데의 입력칸에 쓴 내용은 **검색창이 비어 있어도 항상 적용**되고, 검색창에 입력한 내용과 **둘 다** 만족하는 방만 보입니다. 쓰는 법은 검색창과 같습니다.

예를 들어 기본 필터에 `-욕설방`이라고 써 두면, 검색창에 무엇을 쳐도 "욕설방"이 들어간 방은 항상 숨겨집니다.

기본 필터가 비어 있지 않으면 창에 **프록시 동작 중... (기본 필터 적용 중)** 이라고 표시됩니다. 방이 이상하게 적게 보일 때는 기본 필터를 확인해 보세요.

체크박스나 기본 필터를 바꾼 뒤에는 방목록 패널을 닫았다가 다시 열어야 반영됩니다. 검색창에 치는 검색어는 바로 적용됩니다.

## 설정 저장

체크박스와 기본 필터는 프로그램을 종료해도 유지됩니다. 실행 파일 옆의 `scr-game-filter.json` 파일에 자동으로 저장됩니다. 초기화하려면 이 파일을 지우면 됩니다.

## 알아 두세요

- **인터넷 설정을 잠깐 바꿉니다.** 동작하는 동안 윈도우의 프록시 설정을 이 프로그램으로 바꿔 두고, 종료하면 원래 값으로 돌려놓습니다. 그래서 켜 둔 동안에는 이 컴퓨터의 다른 프로그램 인터넷 연결도 이 프로그램을 거쳐 지나갑니다(내용은 건드리지 않고 그대로 전달합니다).
- **비정상 종료에도 복구됩니다.** 프로그램이 갑자기 꺼져도 함께 실행되는 보조 프로세스가 설정을 원래대로 돌려놓습니다. 그래도 인터넷이 안 되는 것 같으면 이 프로그램을 한 번 실행했다가 닫으세요.
- **게임 프로그램 자체는 건드리지 않습니다.** 스타크래프트에 파일을 끼워 넣거나 게임 메모리를 수정하지 않습니다. 대신 게임이 방목록 화면을 불러오는 길목에서 검색 부분만 바꿔 줍니다.
- **프록시 설정을 바꾸는 다른 프로그램과 같이 켜지 마세요.** 서로 설정을 덮어써서 둘 다 제대로 동작하지 않습니다.
- **게임이 업데이트되면 안 될 수 있습니다.** 게임의 방목록 화면 구조가 바뀌면 동작하지 않을 수 있습니다. 이 경우 프로그램을 새로 받거나 수정이 필요합니다.
- **공식 프로그램이 아닙니다.** 블리자드와 관련이 없는 개인 도구이며, 사용에 따른 책임은 사용자 본인에게 있습니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 검색이 예전처럼 한 단어만 됩니다 | 프로그램을 켠 뒤에 방목록 패널을 닫았다가 다시 열어 보세요. |
| 시작할 때 "포트 28898 바인드 실패" 메시지가 뜹니다 | 이 프로그램이 이미 켜져 있거나, 다른 프로그램이 같은 포트를 쓰고 있습니다. 둘 중 하나만 켜세요. |
| 방이 너무 적게 보입니다 | 기본 필터와 체크박스 항목을 확인하세요. |
| 인터넷이 안 됩니다 | 이 프로그램을 한 번 실행했다가 창을 닫으세요. 그래도 안 되면 윈도우 설정의 프록시 항목이 꺼져 있는지 확인하세요. |
| 백신이 경고합니다 | 서명되지 않은 개인 프로그램이고 프록시 설정을 바꾸기 때문에 의심 프로그램으로 보일 수 있습니다. 아래 파일 확인 방법으로 받은 파일이 맞는지 확인하세요. |

## 받은 파일이 맞는지 확인하기

Releases의 각 버전 설명에 `SHA256` 값이 적혀 있습니다. 받은 파일의 값이 같은지 확인하려면 PowerShell에서 다음을 입력합니다.

```
Get-FileHash .\scr-game-filter.exe -Algorithm SHA256
```

출력된 값이 Releases에 적힌 값과 같으면 같은 파일입니다. 이 파일은 깃허브가 이 저장소의 소스 코드로 직접 빌드해서 올린 것입니다.
